# 常见问题

### 不装 Python 能用吗？
可以，直接用 Windows 桌面 Excel 打开根目录表格并手填。自动导入和更新脚本才需要 Python。

### 角色未收录怎么办？
先核对当前快照版本与名字，再在配装数据库补充推荐或更新 WIKI。总表固定 133 行，新增下拉选项不等于自动扩展主表；不要盲目插行，以免破坏公式范围。

### 圣遗物评分为什么低？
检查五件是否齐全、强化等级、副词条名称与数值是否正确；不同角色按各自 WIKI 优先级评分，查看总表调整建议。

### 面板怎么填？
总表 Z:AF 填当前面板；暴击率、暴伤、充能填百分数数字（85、180、130），不要填 0.85。注意与参考配装条件一致。

### 为什么没判已练好？
检查推荐武器、武器等级、五件圣遗物评分、天赋及面板。缺参考面板时不会自动判已练好，必要时补数据库参考或使用手动标记。

### 今日练谁没有某人？
它是五个自选槽位，不自动排名。先选择角色；已练好标记会隐藏详细规划内容，选择单元格仍保留名字。

### 公式为什么改不了？
白格公式已保护。需要修改前先备份，再到审阅撤销工作表保护，无密码；日常只填浅黄格。

### 推荐武器或毕业标准想自己改？
在配装数据库改黄色输入，参考卡可通过 B32:H32 覆盖参考面板。参考卡覆盖只对引用它的公式生效，不会改写数据库。

### 更新会覆盖手填吗？
更新我的数据会写入接口返回的游戏字段并备份主表，未触及的备注和标记保留；缺失字段可能保留旧值。更新数据则重建空白表，请先备份，两个入口不能混用。

### 多人可以共用吗？
建议每人保留独立的完整目录和 Cookie，避免覆盖彼此主表、账号缓存和备份。空白模板可以分享，个人副本不要公开上传。

### 打开显示空白评分怎么办？
未拥有角色按设计不显示评估；已有角色请检查 Excel 的公式计算模式是否为自动，再按 Ctrl+Alt+F9 完整计算。发布模板无预计算缓存，首次打开需计算。

### 能用 WPS、网页版或其他系统吗？
本发布面向 Windows 桌面 Microsoft Excel。其他软件未承诺兼容，尤其下拉、图表和公式。未提供其他系统启动器。

### Cookie 失效或风控怎么办？
先查看[更新与导入](更新与导入.md)，重新获取官方 Cookie；1034 时降低频率稍后再试，不要把 Cookie 发给别人。

### 只下载 Excel 后能导入吗？
自动导入需要完整目录（源码、数据和依赖）。请到 Releases 下载完整 ZIP 再解压；单独 Excel 适合手工记录。
