# 更新与导入（Windows）

## 环境

手动使用 Excel 不需要 Python。使用自动导入和 WIKI 更新时安装 Python 3.9 或更新版本（python.org，安装时勾选 Add Python to PATH），在解压目录终端运行：

```powershell
py -3 -m pip install -r requirements.txt
```

启动器先寻找 `py -3`，再寻找 PATH 中的 `python`。没有 Python 或依赖时会给出安装提示。不要只下载 `.bat` 或移动 `_source`，请解压完整发布包。

## 四个启动器

- `检查米游社Cookie.bat`：验证 Cookie、在本机终端列出绑定游戏角色，不写入工作簿。
- `导入米游社数据.bat`：读取根目录主表作为模板，输出 `原神角色养成管理表_我的数据_时间.xlsx`，保留原表。
- `更新我的数据.bat`：从主表生成更新结果，自动备份到 `旧版本/`，再写回主表；保留未被接口覆盖的手填内容。
- `更新数据.bat`：重抓公开 WIKI、更新配装与面板，备份并重建根目录空白表。**这会把主表重建为空白表，不能用于刷新个人账号。**

离线重建使用随包 JSON，无需网络或网页缓存：

```powershell
py -3 _source/update_data.py --offline
```

同样会备份并重建主表。不要在 Excel 打开主表时运行写入脚本。

## 获取 Cookie

浏览器登录米游社，按 F12 → Application/应用（或 Storage/存储）→ Cookies。复制 `.mihoyo.com` 下的 `ltuid_v2`、`ltoken_v2`，可带 `ltmid_v2`；不要误用 `.miyoushe.com` 的其他 Cookie。

根目录自行新建 `米游社cookie.txt`，以 `名称=值; 名称=值` 一行保存真实值。也支持 Cookie-Editor JSON 和 Netscape 格式。**不要把 Cookie 发到 Issue、聊天或代码仓库。** 获取不到相应 Cookie 时，不要猜值，请先重新登录官方站点。

先运行检查，再运行导入。多游戏角色时终端会提示选择。高级参数见：

```powershell
py -3 _source/import_miyoushe.py --help
```

默认使用 `client_type=2` 与原有 DS1 方案。接口是否可用受官方变更、账号状态和风控影响，交接记录中的实测不代表当前环境已验证。

## 常见错误

- `1034`：风控。角色一览请求失败时，如果本机存在对应账号缓存，脚本尝试继续使用缓存；不是所有请求都支持缓存兜底。缓存可能过时，无缓存则稍后重试，不要高频请求。
- `10001` 或 `-100`：登录凭据失效或不完整，重新登录并保存 Cookie。找不到本地 Cookie 文件时直接显示获取指南。
- `PermissionError`：先关闭 Excel，检查文件是否只读。
- 缺依赖：使用与启动器相同的 Python 安装 requirements。

## 安全与限制

只在本机读写 Cookie 和账号数据，访问米游社官方接口；不向本项目服务器发送数据（项目没有后端）。请求会把 Cookie 发送给官方接口用于身份验证。原始账号缓存位于 `_wiki_tmp/miyoushe/`，备份位于 `旧版本/`，均含个人数据，禁止分享。用完可删除 Cookie；删除缓存将失去缓存兜底。

只读取游戏信息，不修改游戏；圣遗物仅限已装备部分，不含背包全部库存。旅行者按接口返回的元素形态映射，不保证一次导入所有形态。接口未返回或零值字段可能保留原有输入，导入后应核对面板与装备。

公式默认交给 Excel 自动重算。如已有 LibreOffice Kit，可设置 `LIBREOFFICE_KIT_CLI` 指向其 `cli.js`、`NODE_EXE` 指向 Node 可执行文件；不配置即可跳过。本项目不附带该工具，也不依赖作者电脑路径。
